# 公开范围

本仓库是用于技术审阅的独立代码快照，源自 NeonArena 0.31。它不包含原私有工程的提交历史，也不是公开完整游戏或素材包。

包含：项目运行时代码、相关测试源码、玩法说明、历史测试结果摘要及代码哈希清单。自动录制/取证脚本与本机路径没有纳入发布。

未包含：用户提供的角色与敌人模型、血之光工程、泰坦陨落模型、卫星城网格/贴图、废墟模型、来源不明的熔岩和枪声音频；全部 FBX/Blend/VRM/PMX/PNG/JPG/音频/视频、场景与预制体、导出的骨骼或网格数据、Library/构建文件、原始压缩包及原私有Git历史。

完整工程的包内条款存在禁止工程随意传播、禁止再分发、限制用途及授权不明确等情况，因此不直接切换原仓库可见性。截图/录像也没有自动附上，不把“可以下载模型”解释成“可以公开其源文件”。

源码保留原运行逻辑中的资源名与API引用，但并未包含相应资源。阅读代码不需要完整资产；编译与运行则需要另行提供有适当授权的资源和场景接线。

作者/工具边界：本项目有AI辅助代码与工具生成；实际求职介绍应以本人能解释和演示的设计、实现和调试工作为准。没有对全部代码或第三方内容添加一揽子开源许可。
